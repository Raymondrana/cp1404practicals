## Clean Code Lessons Learned

- **Single Responsibility Principle (SRP):** Breaking programs into small, focused functions where each function does
  one clear job.
- **Meaningful Naming:** Using descriptive names for variables, functions, and constants so code reads clearly without
  needing excessive comments.
- **Consistent Patterns:** Applying standard patterns for menus, input validation, and file handling to reduce bugs and
  improve readability.
